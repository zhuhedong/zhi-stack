# 设计核查与修复

日期：2026-09-09。依据：[Style_Design.md](../dosc/Style_Design.md)、[Apple Light 原型](../dosc/infohub_apple_light.html)。服务端继续使用用户指定的 PostgreSQL。

## 窗口结构纠正

按用户最新反馈，原型外围的展示画框不应成为产品窗口。已取消大屏 32px / 小屏 16px 的外围留白、主容器圆角/边框/投影，内容在所有尺寸下直接铺满可用区域。环境光仍作为应用内部背景，保持亮色玻璃材质。

已删除 `WindowControls` 组件及对应样式、状态监听和拖拽标记。36px 顶栏只保留业务操作；浏览器不渲染桌面窗口按钮。Tauri 改为 `decorations: true`、`transparent: false`，由操作系统绘制一套原生窗口控件。

同时纠正两项打包问题：默认标识 `com.tauri.dev` 被 Tauri CLI 拒绝，已更改为 `local.zhistack.infohub`；`onCloseRequested` 的 SDK 实现会在通过未保存检查后调用 `destroy()`，补充了仅作用于主窗口的 `core:window:allow-destroy` 权限，移除已不再使用的自定义窗口控制权限。

| 标题栏与桌面窗口不符合实际产品要求   | 36px 业务工具栏；系统原生标题栏与窗口按钮；关闭时保留未保存内容检查，取消 HTML 三色按钮和模拟画框                                   |

| 标题、输入框和滚动条参数不符         | 系统字体栈、12px 基础字号、H1 24px/700、H2 14px/600；输入框圆角 8px，聚焦蓝色边框；6px 滚动条、10px 滑块圆角、黑色 10% 滑块         |

| 多份设计稿互相冲突                   | 两份旧深色配色页添加可见停用提示与当前规范链接；新增 `dosc/README.md` 说明优先级，`docs/README.md` 提供入口                         |

生产构建验收曾发现显式重复的 `-webkit-backdrop-filter` 使压缩结果只保留前缀属性。源码改用标准属性，由构建器补充兼容前缀；最终 CSS 同时保留标准属性，避免主窗口和侧栏失去模糊材质。

## 人工界面验证

上轮浏览器已核对 1440×900 桌面三栏、标题与输入框字号/尺寸、API 双列索引、顶部发送按钮和合并请求头。实测业务工具栏 36px、导航 208px、列表 320px、画布 768px、H1 24px/700、输入框圆角 8px；当时的外围画框和 12px 三色按钮已在本轮取消。

通过键盘操作完成以下交互复验：

- 编辑全局 Authorization；添加小写 `authorization` 专属字段，合并表格和 cURL 均只使用覆盖值。
- 停用专属字段后，合并表格恢复全局继承值；再次启用、保存、切换资产后重新打开，参数仍保留。
- 从新位置发送真实 PATCH 请求，返回 HTTP 201；上游回显确认 Authorization 使用已保存的专属值，JSON 请求体和 URL 正确。
- 在 320px 展开导航、切换分类和返回列表；在 375px 打开/关闭新建资产弹窗；在 414px 阅读文章；在 768px 使用折叠导航。对应操作入口均存在并可由键盘触发。

正式页面 `http://127.0.0.1:3210/` 已确认返回最新构建，健康检查确认 PostgreSQL 正常；正式库保持未初始化。本轮浏览器验收使用的独立测试服务和数据库已清理，浏览器视口已还原。

验证限制：本轮 Chrome 明确提示扩展弹窗阻止自动化，桌面自动化报告原生管道不可用（系统错误 2），因此没有把最新窗口的目视/点击检查记为通过；以源码、生产 CSS 和实际 Tauri 构建核查结果为准。未声明整页 WCAG 对比度认证：用户指定的 Apple 蓝和透明度文字层级按设计要求保留。
