# InfoHub 0.2.2

日期：2026-09-11。本版统一确认弹窗、表单错误提示和键盘交互。

## 本版变化

排查并替换运行界面中的 15 处原生 `window.confirm`：放弃编辑与收录、项目切换、会话过期、闲置锁定、桌面窗口关闭、文章同步、历史恢复、删除附件、请求环境、请求历史和反馈，以及清空统计。

确认框使用现有圆角、磨砂遮罩、字体与按钮样式，危险操作使用明确的操作名称和红色按钮。默认聚焦取消，回车不会直接执行删除；Esc 只关闭最上层确认，关闭后焦点返回原按钮。多个确认请求依次处理，发起页面离开或目标切换时自动取消，防止过期操作继续执行。

13 个表单统一使用页面内错误提示，保留必填、URL、长度、数字范围和确认文字等约束。校验失败时阻止提交并聚焦字段，支持读屏错误关联。备份文件选择按钮也使用项目样式。项目面板按需加载，首包保持在 500 kB 以内。

桌面关闭时先阻止默认退出，再等待用户确认，重复关闭事件只显示一个确认框。浏览器刷新或关闭页面时的离开提醒由浏览器控制，保留它以保护未保存内容；系统文件选择窗口也仍由操作系统提供。
