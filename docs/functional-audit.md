## 本轮发现并修复

| 问题与触发方式                                              | 修复后的行为                                                           | 回归证据                                             |
| ----------------------------------------------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------- |
| 新建/编辑弹窗输入后关闭窗口未检查草稿；取消收录直接丢失输入 | 弹窗草稿和进行中的提交纳入关闭保护；取消时确认丢弃                     | 组件：关闭事件、取消、提交期间关闭                   |
| 从文章分类新建再改为凭证，自动锁定漏掉表单                  | 根据当前表单类型清理凭证草稿；锁定时禁止选择凭证，文章草稿保留         | 组件：15 分钟定时器、锁定事件                        |
| 保存期间继续输入，后续内容误标为已保存                      | 对比提交时的编辑版本，后续修改继续显示未保存，下次提交使用新 revision  | 组件：延迟响应期间输入并再次保存                     |
| 切换资产后旧保存/同步返回，可能清除另一条资产草稿或重置视图 | 已卸载编辑器不更新父级草稿；同步和收藏只重置对应资产，更新期间阻止编辑 | 组件延迟保存；同步/收藏源码复核                      |
| 接口 A 返回时已切到 B，结果显示在 B 下                      | 切换接口或修改参数后忽略过时响应                                       | 组件：延迟请求后切换接口                             |
| 文章相对链接被解析到 InfoHub 地址                           | 按文章来源 URL 解析相对链接                                            | 组件：相对路径及锚点                                 |
| OpenAPI 同步用旧参数数组覆盖新规范，新增必填参数消失        | 按参数名合并旧值，保留新增定义；Header 名兼容大小写                    | 旧程序新增 `tenant` 回归失败，修复后真实 PG 检查通过 |
| 嵌套错误/外部 `$ref` 静默转为空样例，不支持的版本仍能导入   | 拒绝错误引用和版本；保留递归模型及示例中的普通 `$ref` 文本             | 单元、集成：缺失/外部/循环引用及版本                 |
| Swagger 2 `consumes: text/plain` 被当作 JSON                | 使用声明的 Content-Type，文本正文不额外加 JSON 引号                    | YAML 导入与实际字段断言                              |
| 调试二进制接口后 UTF-8 替换字符破坏下载                     | 二进制无损传递，界面提示下载原始文件                                   | 集成 PNG 字节比对、组件下载字节比对                  |
| HEAD cURL 只改方法，未开启 curl 仅头部模式                  | 生成 `curl --head`，HEAD/GET 不发送正文                                | 请求编译测试                                         |
| 非法统计值可能入库，导致图片数量等位置渲染失败              | Stars/Forks/Watchers/图片数量必须为非负整数                            | 集成：对象、负数拒绝入库                             |
| J/K 抢占 Ctrl/Alt/Cmd 组合键，窄屏搜索焦点早于布局更新      | 仅普通键导航，搜索在布局更新后聚焦，事件目标做类型检查                 | 组件：快捷键；窄屏焦点仍待浏览器复测                 |
