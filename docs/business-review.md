## 复现

```powershell
cargo build --manifest-path server/Cargo.toml
npm run test:integration
$env:RUN_NETWORK_TESTS = '1'
node scripts/integration.mjs --keep
```

`--keep` 使用独立的 `http://127.0.0.1:3211` 验收工作台；随机数据库、测试密码及关闭控制文件路径写入 `.local/verification.json`。Ctrl+C 或创建其中记录的 `stopFile` 文件会结束验收并清理测试数据库和临时文件。不要在此工作台保存日常数据。

## 当前边界

- 本轮未重新运行真实 R2、Docker 或 Linux 部署；上轮存储协议与恢复证据见 [存储复查](architecture-review.md)。
- Tauri 测试和构建不代表 Windows 窗口按钮、VS Code/终端实际启动、安装包与另一台机器已经验收。
- OpenAPI 导入不是完整规范解释器。外部引用仍需先打包；multipart 文件、复杂 XML 或特殊表单编码需要手动配置。参数不提供完整的 style/explode 自动序列化系统。
- Markdown 导出为当前正文；不会附带离线图片 ZIP，内部媒体引用仍依赖 InfoHub 登录读取。当前也没有全库导出或凭证批量导出。
- 重新同步文章会用来源正文替换已保存正文；需要独立保留的个人修改应先导出或存成独立笔记。当前没有正文历史版本、回收站或崩溃恢复。
- 关键词检索仍是包含匹配；搜索加密字段需要逐条解密，没有全文或向量索引。普通浏览已不再读取全库正文。
