# InfoHub 0.2.1

日期：2026-09-11。本版调整 Windows 客户端首次连接流程。

## 服务端地址由用户填写

首次打开桌面客户端，直接显示服务端地址输入框。填写自己的 HTTP/HTTPS 地址后，点击“保存并连接”，客户端先将地址写入本机配置文件，再检查服务并显示登录界面。没有配置时不会尝试连接 localhost 或编译时地址。

Windows 配置文件：`%APPDATA%\local.zhistack.infohub\config.json`。设置页“配置文件位置”可展开查看实际完整路径。

```json
{
  "serverUrl": "https://infohub.example.com/api"
}
```

地址支持端口和反向代理路径，自动补齐 `/api`。下次启动自动读取。旧版缓存的地址仅用于预填，需要确认保存一次；配置文件不包含密码或会话令牌。

连接测试不保存地址。保存失败时保留输入和原配置；配置损坏时显示原因并允许重新填写修复。保存采用同目录临时文件替换，合法配置中的其他字段会保留。更换服务器后清除原会话与已输入的主密码，迟到的旧请求不会影响新连接。

浏览器版继续使用当前站点 `/api` 或 `VITE_API_URL`。本版未新增服务端接口或数据库迁移，Windows 客户端可继续连接现有 0.2.0 服务。
